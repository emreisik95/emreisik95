# GitHub Profile README Design

## Objective

Position Emre as a senior backend engineer for European teams. A recruiter should understand his focus, see credible public work, and find a clear contact path within a few seconds.

## Direction

Use a recruiter-first, minimal presentation. Replace terminal theatrics, animated typing, activity widgets, and broad icon walls with a distinctive static banner, concise copy, selected engineering work, and restrained technical detail.

The profile will be written in English because the target audience is European hiring teams. It will not publish employer scale, traffic, customer-count, or accuracy metrics.

## Content Structure

1. A custom dark banner establishes a memorable visual identity without relying on a third-party renderer.
2. A one-sentence positioning statement identifies backend and platform engineering as the core specialty.
3. Portfolio, LinkedIn, and email links provide immediate next actions.
4. “What I build” explains backend services and APIs, platform reliability, and commerce integrations.
5. “Selected work” presents Sendthen, Download.fyi, and Wattmeter as concrete evidence of technical range and product ownership.
6. “Engineering focus” lists the deliberately narrow toolset relevant to senior backend roles.
7. “How I work” communicates ownership, simplicity, reliability, and product judgment.
8. A final availability section states EU work authorization and openness to remote or relocation opportunities across Europe.

## Visual System

The profile uses a near-black background, cool white type, muted gray secondary text, and a green accent. The banner is a repository-owned SVG so it is fast, stable, accessible, and visually consistent in light and dark GitHub themes.

## Validation

- Confirm every external URL responds successfully.
- Parse local Markdown to catch malformed links and image references.
- Render the banner and inspect it visually.
- Review the final Git diff for confidential metrics and unsupported claims.
